# S04 — боевая математика

Реализация от 16.10.2026. Основание: предоставленные GDD v1.0, расшифровка v1.4, решения D01–D08 и рабочие численные правила в GDD_REVIEW_RU.md.

## Изменения

- CombatResolver отделён от сцен: уклонение → броня/пробивание → крит → фактическая потеря HP → вампиризм → результат смерти. Возвращает промежуточные значения для диагностики и целые изменения HP.
- Отдельный Heal: крит ×2, ограничение maxHealth, без брони/уклонения/вампиризма и без воскрешения. Полноценный выбор цели и AI жреца относятся к S05.
- ICombatRandom позволяет подставлять точные броски; SeededCombatRandom используется в бою. Детерминированность чистого расчёта не означает детерминированность Unity-физики.
- Общий расчёт подключён к снарядам и массовому урону Shield Bash/Thunderstorm. Их исходные значения 25/45 теперь проходят броню и остальные проверки. Уклонение предотвращает отталкивание/замедление попадания. Это изменение баланса, предусмотренное переходом к формуле блокнота.
- Новый runtime-набор параметров: attacksPerSecond, evasion, critChance, lifeSteal, armorPenetration. Новые проценты у существующих 16 определений по умолчанию нулевые; произвольные значения нового баланса не добавлены.
- Legacy attackSpeed из конфига интерпретируется только как секунды и переводится в атаки/секунду. Исходные численные значения конфига сохранены. Старые сохранения восстанавливают боевые параметры по ID каталога.
- OrbOfSpeed и RapidFire преобразованы через интервал с нижней защитной границей 50 мс. После RapidFire восстанавливается исходная AS, а не прибавляется legacy-число к новой единице.
- CombatStats.Build заново вычисляет базовые параметры и текущие бонусы героя: повторный вызов не удваивает бонусы. Экран характеристик и бой используют один расчёт; UI подписан «Attacks/sec».

## Проверки

Окончательный прогон: валидатор — 16 определений, 4 карты, 0 ошибок; Edit Mode — 66/66; Play Mode — 2/2. Отчёты: Artifacts/S04/tests-final (исходный запуск Logs/Tests/20261016-193011-7d598d97). Windows-сборка: Builds/S04/Windows/ProjectCrusade.exe, успешная сборка подтверждена Artifacts/S04/build-windows.log; SHA-256 сохранён рядом. Headless-запуск до главного меню: без ошибок/исключений в Artifacts/S04/player-smoke.log; процесс остановлен. Проверка запуска не заменяет ручное прохождение. Новые тесты: точные формулы брони/AP, крит до округления, 0/100% и граница вероятности, отдельные броски по целям, overkill и ограничение LS, лечение/крит/overheal, нулевой и дробный урон, мёртвые участники, невалидные AS/NaN/Infinity, большие конечные значения, монотонность защиты, миграция единиц, повторяемость бонусов. Play Mode дополнительно проверяет подключение расчёта к BattleSceneManager и оба HP-текста после урона/LS и промаха, без доступа к игровому сохранению.

## Пределы этапа

Окончательные балансные параметры, таймеры при движении, выбор целей Single/Multi/Heal, общая система эффектов и полный сценарий с жрецом — S05 и последующие этапы. В текущем каталоге не добавлены новые типы бойцов только ради демонстрации расчёта. Ручное прохождение и оценка сложности после смены формулы не заявляются выполненными.
