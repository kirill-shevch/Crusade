# S03 — сохранения, результаты боя и награды

Реализовано 15.10.2026. Сохранение похода централизовано в RunSave; GameManager фиксирует копию состояния только после успешной записи. Технические поля уровня/XP готовы к S07, начисление опыта в этом этапе не добавлялось.

## Поведение

- `Application.persistentDataPath/run.json`: версия формата и модели, JSON внутри конверта с SHA-256. Запись через `.tmp`, Flush и атомарную замену; `.bak` содержит предыдущую рабочую версию.
- Повреждённый основной файл восстанавливается из резервного с видимым сообщением. При следующей записи повреждённый файл архивируется отдельно, рабочая резервная копия сохраняется. Неизвестный новый формат блокирует загрузку, а не откатывается молча. Если обе копии непригодны, они сохраняются для восстановления.
- Ошибка записи показана в игре. Изменение состояния и переход сцены не выполняются до успешного повторения действия. Перестановка отряда откатывается к сохранённым позициям при ошибке.
- Начатый бой хранится до загрузки сцены. Ребро отмечается только при победе. После перезапуска незаконченного боя игрок возвращается на исходный узел и может начать бой заново. Середина боя не сохраняется.
- Победа фиксирует ребро, целевой узел, квитанцию боя и случайно выбранную награду одной записью. Повторное нажатие результата ничего не начисляет. Идентификаторы включают поход и карту.
- Сначала сохраняется выбор награды; затем состав/бонус и отметка получения записываются вместе. Возврат на экран показывает ту же награду. Закрытие экрана сохраняется отдельно, поэтому перезапуск не пропускает незакрытый результат.
- Полный отряд: слияние с новым юнитом, включая каскад; если места всё равно нет — только явный отказ. Исходный отряд сохраняется без замены участников.
- Вход в новый узел без боя тоже открывает его награду. Ранее такие награды пропускались.
- Между картами сохраняются экземпляр героя, отдельные поля уровня/XP и постоянные бонусы. Союзники и обычные бонусы сбрасываются. Выбор следующей карты разрешён только после закрытия конечной награды.
- Поражение/новый поход больше не вызывают PlayerPrefs.DeleteAll. Неактивное сохранение предотвращает повторный импорт старого похода. Новый поход заменяет старый после выбора героя.

## Миграция и ограничения

При отсутствии нового файла читаются старые PlayerPrefs. Юниты получают стабильные ID, итог миграции архивируется в `.legacy.json`; сами PlayerPrefs не изменяются. Преждевременно отмеченное ребро незаконченного боя снимается. Старый формат не хранил квитанций: для уже посещённых узлов предполагается, что награда получена; восстановить пропущенную награду или прежние дубли из него достоверно нельзя.

InnerFire остаётся прежней наградой терминальной карты без боевого эффекта; после закрытия последнего результата поход завершается. Реализация эффекта относится к S08. Формулы боя не менялись.

Оригинальный текст документа-саммаризации недоступен через ссылку на чат: API возвращает заглушки сообщений. Ранее разобраны 10 доступных фотографий блокнота; 2 страницы отсутствуют. Полный документ не объявляется проревьюенным. Для окончательной сверки нужен сам файл или текст.
